ONLINE SERVICE CENTRE WEBSITE — START HERE

FILES
- index.html  : Website page and service content
- style.css   : Colours, layout and mobile responsive design
- script.js   : Mobile menu and contact form behavior

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. For easiest preview, install the VS Code extension "Live Server", right-click index.html, and choose "Open with Live Server".
   You do NOT need npm install or Node.js to run this static starter website.

BEFORE PUBLISHING
1. In index.html, replace:
   - "Add your full shop address here"
   - "Replace with your business number"
   - "Replace with your business email"
2. In script.js, replace YOUR-EMAIL@example.com with your real business email.
3. Check every service description and remove services you do not provide.
4. This starter site does not collect/store submissions on a server and is not connected to government portals.
5. It is not an official government website. Do not ask customers to share OTPs, passwords or sensitive ID details through the website.

IMPORTANT
This is a static frontend starter. Admin login, database, appointment booking, customer records, and online payment require a separate secure backend and should be added only with proper authentication and privacy protections.
